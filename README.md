# Abissinya Restaurant

Welcome to Abissinya Restaurant a web-based application designed to bring the authentic Ethiopian dining experience online.

## Project Description

Abissinya Restaurant is a full-fledged web application developed to serve the needs of a modern restaurant business. 
It offers a variety of features aimed at enhancing the dining experience, whether customers are dining in or ordering takeout.


## Features

### 1. **Interactive Menu**
   - Browse through a diverse range of Ethiopian dishes with detailed descriptions, ingredients, and prices.

### 2. **Online Ordering System**
   - Users can add dishes to their cart, customize their orders, and specify preferences.

### 3. **Table Reservations**
   - Easy-to-use reservation system where customers can select their preferred date, time, and seating options.

### 4. **User Accounts**
   - User registration and login with email and password.

### 6. **Admin Panel**
   - Comprehensive dashboard for restaurant management.
   - Manage menu items, view orders, track reservations, and generate reports.


## Technologies Used

- **Frontend**: Blade with tailwind-css
- **Backend**: Laravel
- **Database**: MySQL
- **Authentication**: Laravel Sanctum
